🐋 Docker Deployment Guide & Commands

Use the following Docker commands to run this Hospital Management System frontend and Hive container stack:

docker compose up -d --build
docker build -t hospital-management-system .
docker run -d -p 8080:80 hospital-management-system
💡 Access URL: Open your browser and navigate to http://localhost:8080 after starting Docker.
